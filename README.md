# Jimothy's Crossing 16-Bit

Jimothy's Crossing redrawn in true 16-bit style: same levels, controls, story and gameplay as the original, with pixel-art sprites, parallax Seattle backgrounds, a pixel font and a 16-bit chiptune soundtrack. Free, no locks. Part of [Peter's Arcade](https://ploug76.github.io/peters-arcade/).

Play: https://ploug76.github.io/jimothys-crossing-16bit/

- `index.html` is built from `src/` by `build.sh` (which also injects the shared leaderboard, board id `jimothys-crossing-16bit`).
- `test/shots.py` screenshots phone sizes and checks layout; `test/bot.py` has a planning bot clear levels 1-2.
